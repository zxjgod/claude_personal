## 🎯 核心功能

### 1. Agent Loop（核心）

```typescript
// 流式 Agent 循环
agentLoop(
  messages: Message[],
  tools: Tool[],
  callModel: ModelCaller,
  modelConfig: ModelConfig,
  options?: LoopOptions
): AsyncGenerator<LoopEvent>
```

**特性**:
- ✅ 流式事件输出（text_delta、tool_use、tool_result）
- ✅ 并发工具执行（安全分组）
- ✅ 自动上下文压缩
- ✅ 错误恢复与重试
- ✅ Token 预算管理

### 2. 工具系统

**核心工具**:
- `read` - 文件读取（支持图片/PDF）
- `write` - 文件写入（原子性保证）
- `edit` - 文件编辑（read-before-edit）
- `bash` - Shell 命令执行
- `grep` - 内容搜索
- `glob` - 文件模式匹配

**扩展工具**:
- `task` - 子代理任务
- `multi_edit` - 批量编辑
- `notebook_edit` - Jupyter Notebook 编辑
- `enter_worktree` / `exit_worktree` - Git 工作树

**工具特性**:
- ✅ 统一 `Tool` 接口
- ✅ 权限检查（mode + dangerous-pattern）
- ✅ 并发安全标记
- ✅ 结果格式化
- ✅ 输入验证

### 3. 安全防护体系

**多层防护**:

```
第一层：输入验证
  ✅ 路径验证（长度、空字节、遍历）
  ✅ 命令验证（fork bomb、设备写入）
  ✅ URL 验证（协议、SSRF）

第二层：权限控制
  ✅ 子代理权限隔离
  ✅ 危险工具审批
  ✅ Workspace 边界检查

第三层：资源限制
  ✅ 文件大小（10MB）
  ✅ 并发工具（10 个）
  ✅ 执行超时（bash 默认 120s，可传参覆盖）
  ✅ 内存监控（1GB）

第四层：监控告警
  ✅ 健康检查
  ✅ 失败率监控
  ✅ 资源使用追踪
```

### 4. 错误处理

**指数退避重试**:
```typescript
// 429 限流重试
Retry 1: ~5s  (2^0 × base, ±20% jitter)
Retry 2: ~10s (2^1 × base, ±20% jitter)
Retry 3: ~20s (2^2 × base, ±20% jitter)
最大延迟: 60s
```

**上下文压缩**:
- 自动检测 context_length 错误
- 渐进式压缩策略
- 最多 3 次重试
