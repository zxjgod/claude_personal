## 已有能力

- 流式多轮执行、工具调用、权限规则、配置 hook 和取消。
- Anthropic 原生与 OpenAI compatible 两种模型 adapter。
- 上下文修剪、可恢复工具内容、模型压缩、重试和 fallback。
- TUI、行式 REPL、headless 入口；磁盘命令、skills、agents 与 MCP。
- 会话恢复、工具文件 checkpoint、长期记忆、子代理与多代理工作流。
- 工作区持久任务与会话任务、空闲交付、排队及取消。

## 适用范围与限制

项目的静态测试和模拟集成不能替代真实 provider、云网关或用户终端的联调。DesignSync 当前不可用，平台专属工具和沙箱能力以实际检测为准。Shell 修改不进入文件回退；部分运行时状态不跨进程保存。当前会话与任务持久化不是跨文件事务或多进程协作数据库。详细边界见 [局限性说明](局限性说明.md)。

项目没有可验证的“100% 对齐官方”或“综合完成度 100%”口径，因此不将这类自评作为当前指标。
