# 项目总览 — claude_personal (Claude Code Replica)

> 更新时间：2026-06-24
> 当前状态：M0–M12 主线完成 + M13.7 `/effort` 完成，综合完成度约 70–75 / 100（以官方 Claude Code 为基准）
> 验证：`tsc --noEmit` 干净 + `vitest run` 全绿（约 37 文件 / 360+ 用例）

一个本地 AI coding assistant，复刻 Claude Code 的 agentic workflow，支持任意 OpenAI 兼容 API 或原生 Anthropic 作为后端。

## 架构

```
CLI (cli.ts / tui/run.tsx)
  → System Prompt Builder (6 静态段 + 动态边界)
  → Agent Loop (AsyncGenerator<LoopEvent>)        ← 核心
       ├─ ModelCaller (provider-agnostic)
       │    ├─ anthropic-adapter (原生 Messages API + prompt cache)
       │    └─ llm-adapter (OpenAI 兼容 + 云网关)
       ├─ Tool 执行 (并发分组 + 流式回传)
       ├─ Permission 检查 + Hooks
       └─ 上下文压缩 (snip → autoCompact)
  → Tools (统一 Tool 接口)
```

核心抽象：用 `AsyncGenerator<StreamEvent>` 统一两个 provider 的输出，agent loop 完全不感知 provider 差异。
