# 文件访问与磁盘模板安全边界

- LSP 诊断和补全的显式文件路径必须位于当前工作区内，并通过敏感路径检查。工具入口与 LSP 客户端都会检查，拒绝时不会启动语言服务或降级运行诊断。
- `/export`、`/share` 的相对路径以当前工作区为基准；工作区内的绝对路径仍可使用。工作区外及敏感配置路径会被拒绝。`/share` 不带路径时仍输出到终端。
- 项目 `.claude/skills`、`.claude/commands` 的模板只展开参数和工作区路径，不执行 shell 扩展、不读取任意环境变量。禁用的 shell 扩展会显示说明。
- 用户目录中的模板可保留字面 shell 命令和环境变量展开。需要这项能力时，请先审阅模板，再安装到用户目录；项目中的同名模板覆盖用户模板时仍按项目权限处理。
- shell 指令内不支持模板参数替换。参数、环境变量值和命令输出不会作为新的模板指令再次执行。需要动态命令时，通过正常的 shell 工具及审批流程执行。

这些检查是应用层边界，并非操作系统沙箱；允许的语言服务仍需正常访问项目依赖。
