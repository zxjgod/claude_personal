# 历史归档

本目录集中保存阶段报告、旧计划、参考分析与已完成的变更记录。它们反映当时的实现和验证结果，行号、数量与完成度评价不代表当前版本。当前维护入口见 [文档索引](../README.md)。

| 目录 | 内容 |
|---|---|
| [reports/](reports/) | 阶段报告、审查记录、交付清单和历史方案 |
| [reference/](reference/) | 恢复版官方源码的模块说明和目录树，非本项目结构 |
| [plans/](plans/) | 原 `.claude/plans/` 中已完成的升级计划 |
| [历史更新记录/](历史更新记录/README.md) | 2026 年 6 至 9 月以及早期 phase 变更记录 |
| [202609-架构审查/](202609-架构审查/) | 2026 年 9 月六个架构分册 |

根目录已有的 ROADMAP、维护快照和对比表仍保留。新变更记录放在 [当前更新日志](../更新日志/README.md)，历史记录不进入 npm 发布包。

旧估算副本和硬编码成本实验脚本于2026-10-07第二轮清理中移除。历史报告保留当时的文件名和验证记录，相关脚本路径不再作为可运行入口。

日期明确的报告与计划使用 `YYYYMMDD-主题.md`。只有年月的快照使用 `YYYYMM-主题.md`；时间标注不足或日期互相矛盾时保持原名，不根据文件修改时间或正文引用日期推测。命名规则与固定入口例外见 [文档索引](../README.md#文档命名)。

2026-10-07 整理时，本地 `reference` 与 `sandbox` 工作区移至仓库外的 `../claude_personal-self-local/`，样例工作区中的会话记录一并保留。已生成的覆盖率报告也移到该目录；可随时运行 `npm run test:coverage` 重新生成。
