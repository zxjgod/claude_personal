# 更新日志 — /effort 布局与 Ultracode 紫色线性扩散

> 日期：2026-09-30
> 类型：feature / fix
> 模块：TUI / EffortPrompt / effort-fx / PromptFooter
> 状态：已落地，待提交

## 用户需求

参考截图：普通 `/effort` 使用中性灰色滑轨，白色指针、淡紫色当前档位、紫色 Ultracode 区段。进入 Ultracode 后，从档位文字中心依次扩散到整个面板，形成紫色像素同心波纹；保留原有档位交互，不更改实际推理策略。

## 改动

- `src/tui/effort-fx.ts`：统一 9 行布局（分隔线、标题、留白、端点文字、滑轨、档位、子标题、留白、操作提示），删除底部当前档位介绍。宽终端滑轨居中并采用 62 列几何；背景画布覆盖终端可用宽度，不再限制为 120 列。
- 普通档位滑轨为主题次要灰色，指针与标题为正文色；Ultracode 区段与名称为 `#8c50f0`。各档位选中色及 Max 彩虹细节按下方追加截图反馈细化。
- 从参考图提取八档紫色背景：`#3e1676`、`#491e87`、`#542799`、`#5f2faa`、`#6b37bc`、`#763fcd`、`#8148df`、`#8c50f0`。移除原有随机垂直抖动、色相偏移与全局呼吸亮度，使用两列像素采样和量化同心波纹。
- 扩散中心位于 Ultracode 档位文字，初始为小块区域，扩散半径随时间线性增大（不再采用平方缓入）。32 帧 × 70ms，约 2.24 秒覆盖整个面板；覆盖后同心波纹继续向外运动。已覆盖文字变为白色加粗，未覆盖部分保留原色。
- 紫色区域从标题行延伸到操作提示行，顶部灰色分隔线保持不变。动画前后行数、文字位置及画布大小一致。
- `src/tui/EffortPrompt.tsx`：切换档位时重置动画相位与扩散进度，重复进入重新从中心扩散。移除重复的底部交互提示，支持 `CCR_REDUCED_MOTION=1` 静态全幅显示。
- `src/tui/PromptFooter.tsx`：仅在 Effort 面板打开时隐藏常规快捷键/模型页脚，取消或确认后恢复；普通与全屏路径共享此逻辑。

## 档位颜色与动画方向（同日追加）

- 从补充截图确认 Low 为 `#ffc107` 黄色，Medium 为 `#4eba65` 绿色（主题 success），High 为 `#b1b9f9` 淡紫色（主题 commandSelected），Xhigh 为 `#af87ff` 紫色。
- Xhigh 增加一字符宽白色扫光，依次从名称最左侧向右侧移动，循环间保留紫色停顿；仅改变字符前景色，不改变文字内容或位置。
- Max 保持截图中的灰色轨道、白色指针及紫色 Ultracode 区段，只让 Max 名称呈现彩色字符。彩色相位递增，使右侧颜色依次移动到左侧，而不是反向流动或把整条轨道染成彩虹。
- Max 名称下方增加截图中的过量 token、耗时/过度思考警告。普通档位面板保持 9 行，Max 单独增加一行；上方滑轨和档位位置不变。
- Xhigh、Max、Ultracode 均遵循减少动态效果模式，退出档位时清理计时器，进入新档位时重置相位。已有 Ultracode 紫色线性扩散保留。
- 新增精确颜色与流动方向帧回归、Xhigh 动态组件回归，并覆盖三个动态档位的静态偏好设置。
- 补充后相关 7 个测试文件、139 项测试通过；类型检查通过。

## 初始尺寸与流速微调（同日追加）

- Ultracode 初始扩散半径由 7 缩小为 2.5，从名称中心更小的紫色区域开始；线性扩散时长与最终覆盖范围保持不变。
- Xhigh 扫光由纯白改为淡紫色 `#d0b4e8`，每字符移动间隔由 70ms 延长为 160ms，降低亮度并减慢由左向右的流动。
- Max 彩虹更新间隔由 110ms 缩短为 60ms，相位步长由 15° 增大为 20°，整体由右向左流动速度约为此前的 2.4 倍。
- 增加初始扩散范围、扫光精确颜色、Xhigh 与 Max 更新间隔及动态帧回归；减少动态效果模式保持静态。
- 微调后相关 7 个测试文件、140 项测试通过；相关 Biome 检查、`tsc --noEmit`、`git diff --check` 与 `npm run build` 均通过，已更新本地运行产物。
