# 更新日志 — 命令菜单灰色与淡紫色选中主题

> 日期：2026-09-30
> 类型：fix
> 模块：TUI / 命令补全 / 主题
> 状态：已落地，待提交

## 用户需求

参考截图中的 `/` 菜单：普通命令与说明为灰色，选中项的命令与说明统一淡紫色。当前项目为蓝色普通命令、橙色选中项，且说明继承 dim 效果，颜色明显不同。

## 改动

- `src/tui/theme.ts` 新增独立的 `commandSelected`，暗色主题 `#b1b9f9`、浅色主题 `#4b50a8`，随 `applyTheme` 实时切换。不改变用于文件补全、会话选择等其他面板的 `command` 与 `accent`。
- `src/tui/InputBox.tsx`：`/` 补全菜单普通行采用 `palette.secondary`（暗色为 `#999999`）；选中行采用 `palette.commandSelected`。命令名称与描述同色，移除描述的额外 dim 效果。
- `src/tui/CommandPicker.tsx`：`/help` 命令选择菜单使用同一行颜色规则，边框与标题改为中性灰色。
- `src/tui/cli-interactive.ts`：`--no-tui` 的原始 TTY 命令补全同步上述配色。
- 保留菜单导航、选中箭头、过滤、可见行数和输入框结构。本次只对齐命令菜单的主题颜色，不扩大到整个应用。

## 验证

新增 ANSI 输出回归，覆盖 `/` 普通/选中整行颜色、方向键切换与 `/help`；原始 TTY 回归检查同色名称和描述；主题测试检查暗/浅切换后颜色恢复。相关测试、类型检查和构建结果见交付说明。

- 命令颜色、主题切换、原始 TTY、输入框与 TUI 组件共 5 个测试文件、95 项测试通过。
- `tsc --noEmit` 通过；主题、命令选择菜单与新增颜色测试通过 Biome 检查。

## 说明列布局对齐（同日追加）

- `/` 命令说明不再紧跟长短不同的命令名称，而是统一从第 31 个字符单元开始（左侧预留 30 列，包含选中箭头）。长命令自动扩展名称列；窄终端将名称列限制在可用宽度的一半。
- 新增 `src/tui/command-menu-layout.ts`，供 InputBox、CommandPicker 和原始 TTY 共用。列宽根据完整命令目录计算，不随可见列表滚动或筛选变化；按终端显示宽度处理中文命令，过长名称/说明使用省略号截断，避免挤占下一行。
- 保留已有灰色/淡紫色配色、选中箭头、菜单导航和输入框结构；本次只对齐命令名与介绍的双列布局。
- 新增列对齐、长名称、中文显示宽度、窄终端和长说明回归，更新 ANSI 整行配色测试。相关 5 个测试文件、93 项测试通过。

构建并重启项目后输入 `/`。默认暗色主题为灰色普通行、淡紫色选中行；`/theme light` 使用浅色背景对应的高对比配色。截图最终观感还受终端字体与色彩支持影响。
