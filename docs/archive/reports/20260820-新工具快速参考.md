## 🤖 Agent — 增强的子 Agent 生成器

**用途**: 启动具有高级功能的子 agent（worktree 隔离、努力级别控制）

**API**:
```typescript
Agent({
  prompt: string,                    // 必需: 任务指令
  description?: string,              // 可选: 简短描述
  subagent_type?: string,           // 可选: agent 类型（省略则 fork）
  model?: string,                    // 可选: 模型覆盖
  effort?: "low"|"medium"|"high"|"xhigh"|"max",  // 可选: 推理级别
  isolation?: "worktree",           // 可选: Git worktree 隔离
  run_in_background?: boolean       // 可选: 后台运行
})
```

**示例**:
```typescript
// 在隔离环境中重构代码
Agent({
  prompt: "Refactor the auth module to use async/await",
  description: "Auth refactor",
  isolation: "worktree",
  effort: "high"
})
```

**别名**: `agent`

## 📋 结构化任务管理 (4 个工具)

### 1. TaskCreate — 创建任务

```typescript
TaskCreate({
  subject: string,           // 必需: 任务标题（祈使句）
  description: string,       // 必需: 详细描述
  activeForm?: string,       // 可选: 进行中显示文本
  metadata?: object          // 可选: 自定义元数据
})
```

**示例**:
```typescript
TaskCreate({
  subject: "Fix authentication bug",
  description: "Login returns 500 when password contains special chars",
  activeForm: "Fixing authentication bug",
  metadata: { priority: "high", estimate: "2h" }
})
// => Created task 1: Fix authentication bug
```

### 2. TaskGet — 获取任务详情

```typescript
TaskGet({ taskId: string })
```

**示例**:
```typescript
TaskGet({ taskId: "1" })
// => Task 1: Fix authentication bug
//    Status: pending
//    Description: Login returns 500 when...
//    Metadata: {"priority":"high","estimate":"2h"}
```

### 3. TaskUpdate — 更新任务

```typescript
TaskUpdate({
  taskId: string,
  status?: "pending" | "in_progress" | "completed" | "deleted",
  subject?: string,
  description?: string,
  owner?: string,
  metadata?: object,         // 合并元数据（null 删除键）
  addBlocks?: string[],      // 此任务阻塞的任务
  addBlockedBy?: string[]    // 阻塞此任务的任务
})
```

**示例**:
```typescript
// 开始工作
TaskUpdate({ taskId: "1", status: "in_progress", owner: "alice" })

// 设置依赖（Task 2 依赖 Task 1）
TaskUpdate({ taskId: "2", addBlockedBy: ["1"] })

// 完成任务
TaskUpdate({ taskId: "1", status: "completed" })

// 更新元数据
TaskUpdate({ 
  taskId: "1", 
  metadata: { estimate: "3h", actual: "2.5h" } 
})
```

**状态转换**:
```
pending → in_progress → completed
   ↓
deleted (任何状态可直接删除)
```

### 4. TaskList — 列出所有任务

```typescript
TaskList()
```

**示例**:
```typescript
TaskList()
// => Tasks (3):
//    1. [pending] Setup database (owner: alice)
//    2. [in_progress] Implement API [blocked by: 1]
//    3. [completed] Write tests
```

## ⏰ Cron 调度管理 (3 个工具)

### 1. CronCreate — 创建定时任务

```typescript
CronCreate({
  cron: string,              // 必需: 5 字段 cron 表达式
  prompt: string,            // 必需: 执行的提示
  recurring?: boolean,       // 可选: 循环 (default: true)
  durable?: boolean          // 可选: 持久化 (default: false)
})
```

**Cron 格式**: `分钟 小时 日期 月份 星期` (本地时区)

**示例**:
```typescript
// 工作日每天 9 点
CronCreate({
  cron: "0 9 * * 1-5",
  prompt: "Generate daily report",
  recurring: true,
  durable: true
})
// => Scheduled recurring job job-abc123-1

// 每 5 分钟
CronCreate({ cron: "*/5 * * * *", prompt: "Check system health" })

// 每月 1 日午夜
CronCreate({ cron: "0 0 1 * *", prompt: "Monthly backup" })

// 一次性任务（圣诞节）
CronCreate({
  cron: "0 9 25 12 *",
  prompt: "Send holiday greetings",
  recurring: false
})
```

**常用 Cron 表达式**:
```
"0 9 * * *"      — 每天 9:00
"*/5 * * * *"    — 每 5 分钟
"30 14 * * *"    — 每天 14:30
"0 0 * * 0"      — 每周日午夜
"0 9 * * 1-5"    — 工作日 9:00
"0 0 1 * *"      — 每月 1 日午夜
"0-30 9-17 * * 1-5" — 工作日 9-17 点每小时前半小时
```

**别名**: `schedule_cron`, `cron_create`

### 2. CronDelete — 取消定时任务

```typescript
CronDelete({ id: string })
```

**示例**:
```typescript
CronDelete({ id: "job-abc123-1" })
// => Job job-abc123-1 cancelled and removed.
```

**别名**: `cron_delete`

### 3. CronList — 列出所有定时任务

```typescript
CronList()
```

**示例**:
```typescript
CronList()
// => Scheduled jobs (3):
//    job-abc123-1: "0 9 * * 1-5" [recurring, durable]
//    job-abc123-2: "30 14 25 12 *" [one-shot, session-only]
//    job-abc123-3: "*/30 * * * *" [recurring, session-only]
```

**别名**: `cron_list`

## 🎯 完整工作流示例

### 示例 1: 并行开发流程

```typescript
// 1. 创建主任务
TaskCreate({
  subject: "Implement user authentication",
  description: "Add JWT-based auth system",
  metadata: { sprint: "2024-Q1", epic: "AUTH-001" }
})

// 2. 创建子任务
TaskCreate({
  subject: "Setup database schema",
  description: "Create users table with indexes"
})

TaskCreate({
  subject: "Implement login endpoint",
  description: "POST /api/auth/login with JWT generation"
})

TaskCreate({
  subject: "Write authentication tests",
  description: "Unit and integration tests for auth flow"
})

// 3. 设置依赖关系
// Login 依赖数据库
TaskUpdate({ taskId: "3", addBlockedBy: ["2"] })
// 测试依赖 Login
TaskUpdate({ taskId: "4", addBlockedBy: ["3"] })

// 4. 分配工作
TaskUpdate({ taskId: "2", status: "in_progress", owner: "alice" })

// 5. 使用 Agent 工具在隔离环境中工作
Agent({
  prompt: "Implement the database schema from task 2",
  subagent_type: "code-explorer",
  isolation: "worktree"
})

// 6. 完成并继续
TaskUpdate({ taskId: "2", status: "completed" })
TaskUpdate({ taskId: "3", status: "in_progress", owner: "bob" })
```

### 示例 3: 项目冲刺管理

## 🔗 工具组合建议

### Agent + 任务管理
```typescript
// 创建任务
const task = TaskCreate({
  subject: "Refactor authentication module",
  description: "Convert callbacks to async/await"
});

// 启动 Agent 完成任务
Agent({
  prompt: `Complete task ${task.id}: ${task.description}`,

  effort: "high"
```

## 💡 最佳实践

### 1. 任务管理
- ✅ 使用祈使句命名任务（"Fix bug"，不是 "Bug fixing"）
- ✅ 在 `activeForm` 中使用现在进行时（"Fixing bug"）
- ✅ 明确设置依赖关系，避免循环依赖
- ✅ 只在任务**完全**完成后才标记 `completed`
- ✅ 使用 `metadata` 存储自定义字段（优先级、预估时间等）

### 2. Cron 调度
- ✅ **避开 :00 和 :30** 分钟以分散负载
- ✅ 使用 `durable: true` 用于长期任务
- ✅ 使用 `recurring: false` 用于一次性提醒
- ✅ 在 Cron 表达式中验证时区（使用本地时间）
- ✅ 定期检查 `CronList()` 清理不需要的任务

### 3. Agent 工具
- ✅ 仅在**并行文件修改**时使用 `isolation: "worktree"`（开销大）
- ✅ 对简单任务使用 `effort: "low"` 以节省成本
- ✅ 对需要深度推理的任务使用 `effort: "high"` 或 `"xhigh"`
- ✅ 使用 `run_in_background: true` 用于长时间运行的任务
- ✅ 提供清晰的 `description` 以便在 UI 中识别

## 🚨 注意事项

### 结构化任务
- ⚠️ 任务 ID 仅在会话内有效（跨会话不共享）
- ⚠️ 当前版本任务不持久化（重启丢失）
- ⚠️ 删除任务不会自动清理依赖关系

### Cron 任务
- ⚠️ 仅在 REPL 空闲时触发（不是严格的时间保证）
- ⚠️ `durable: true` 的持久化实现待完成
- ⚠️ 所有 Cron 表达式使用**本地时区**

### Agent 工具
- ⚠️ `isolation: "worktree"` 需要 git 仓库
- ⚠️ Worktree 创建有 200-500ms 开销
- ⚠️ 失败时 worktree 可能未清理（手动运行 `git worktree prune`）
