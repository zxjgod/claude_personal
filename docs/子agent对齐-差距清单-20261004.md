## 一、官方规格要点（已核实原文）

### 内建子代理
- **Explore**：只读（Write/Edit denied），跳过 CLAUDE.md 与 git status 快照；调用时可带
  thoroughness 级别（quick / medium / very thorough）。
- **Plan**：plan 模式下做调研的只读代理，同样跳过 CLAUDE.md。
- **General-purpose**：拥有子代理可用的全部工具。
- 其它辅助代理：`claude`（兜底/后台会话默认）、`statusline-setup`(Sonnet)、
  `claude-code-guide`(Haiku)。
- 同名用户/项目代理覆盖内建；`permissions.deny` 可禁用某个类型或整个 Agent 工具；
  `CLAUDE_CODE_DISABLE_EXPLORE_PLAN_AGENTS=1` 移除 Explore/Plan；
  非交互/SDK 下 `CLAUDE_AGENT_SDK_DISABLE_BUILTIN_AGENTS=1` 移除全部内建。
- **2.1.202 二进制实测**：省略 `subagent_type` 时使用 general-purpose（工具描述原文：
  "If omitted, the general-purpose agent is used."），fork 需显式 `subagent_type:"fork"`
  且受 `CLAUDE_CODE_FORK_SUBAGENT`/tengu 实验闸门控制。
- **2.1.202 二进制实测**：类型名归一化（NFKC→小写→去空白/连字符/下划线，截 60 字符），
  唯一命中自动解析、多命中报歧义错误；总嵌套深度上限 S8t=5；内建 Explore/Plan 是
  拒绝名单制（仅禁 Agent/Artifact/ExitPlanMode/Edit/Write/NotebookEdit）；
  general-purpose 为 `tools:["*"]`；另有 `whenToUseLean` 精简描述变体。

### Frontmatter 字段（.claude/agents/*.md 与 ~/.claude/agents/*.md）
`name` / `description` / `tools`（省略=继承全部可用工具）/ `disallowedTools` /
`model`（sonnet|opus|haiku|inherit|具体名）/ `permissionMode` / `skills` / `hooks` /
`memory`（user|project|local）/ `background` / `isolation: worktree` / `effort` /
`mcpServers`（代理级 MCP 作用域，内联 MCP 需信任确认）/ `omitClaudeMd` / `maxTurns`。

### 模型优先级
**2.1.202 二进制实测（B7 函数）**：`CLAUDE_CODE_SUBAGENT_MODEL` 环境变量 > Agent 工具
调用时的 `model` 参数 > frontmatter `model` > 主会话模型（与文档页面"model 参数覆盖
env"矛盾，二进制为实际行为）。
fork 保持主会话模型（字节级相同前缀 → 命中父 prompt cache；官方 model 参数说明：
"Ignored for subagent_type: 'fork' — forks always inherit the parent model."）。

### Fork
- fork 继承全部：消息历史、系统提示词、工具、权限提示冒泡到主终端；共享 prompt cache。
- **"A fork can't spawn further forks."** fork 不能再 fork。
- fork 可带 `isolation: "worktree"`。
- fork 模式开关：`CLAUDE_CODE_FORK_SUBAGENT=1|0`（交互默认开，headless/SDK 默认关）。

### 多子代理/编排
- 同步子代理共享父 abortController；异步（后台）子代理用全新不链接的控制器。
- 结果回父两条路径：同步 → 最后一条 assistant 文本作 tool_result；异步 → 完成时生成
  `<task-notification>` 注入主循环，父可读 outputFile 取完整输出。
- 子代理可以再 spawn 自己的子代理（typed 嵌套允许；fork 嵌套禁止）。
- 并发上限（"Concurrent subagent limit" 一节）。**2.1.202 二进制排查结论**：
  无全局子代理并发上限常量；workflow 编排并发 = CPU 核数，agent() 调用上限 1000；
  team 成员并发默认 3（与本项目 Task/Agent/Team 各 3 一致）。
- 描述预算：非内建子代理 description 合计超过 15,000 token 时启动告警。
- "Resume subagents"：磁盘持久化代理 + 重启后 orphan-resume + SendMessage agentId
  寻址恢复（2.1.202 二进制证实为大型子系统）。
- "Subagent output scanning"：模型分类器扫描子代理/工具结果做提示注入拦截
  （recordPresumed/shouldBlock，2.1.202 二进制证实）。
- 子代理默认禁用 extended thinking（runAgent.ts:679-684，反编译分析）。
- 子代理转录写入 sidechain（subagents/ 目录）。
