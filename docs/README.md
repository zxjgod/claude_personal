# Claude Code Replica — 项目文档

本目录是 `claude_personal` 的当前文档集。历史版本（旧 ROADMAP、各阶段更新日志、对比表等）见 [`archive/`](./archive/)。

## 文档索引

| 文档 | 用途 |
|---|---|
| [局限性说明.md](./局限性说明.md) | **诚实边界（最该先读）**：无法证实的声明、尚未做到 / 实现偏浅的部分、安全真实水平、技术债 |
| [快速开始.md](./快速开始.md) | 安装、配置、启动、真机联调流程（含原 `启动教程.txt` 内容） |
| [项目总览.md](./项目总览.md) | 架构、模块清单、完成度现状、与官方对齐度（含自评口径，数字以实跑为准） |
| [项目架构.md](./项目架构.md) | **完整模块结构 + 数据流 + 关键机制 + 运行时产物**（改动前先在这里定位） |
| [设计决策](./architecture/decisions.md) | 已接受的取舍与权限、会话位置、调度归属规则 |
| [领域术语](../CONTEXT.md) | 会话、工作区、回合、文件回退点与定时输入的统一词汇 |
| [模块维护方案.md](./模块维护方案.md) | **各模块维护卡**：验证命令、常见故障、影响半径、改动 cookbook、高风险区 |
| [更新日志/](./更新日志/README.md) | **变更记录**：模板 + 索引，每次改动留痕，便于出 bug 时回溯 |
| [项目评审报告.md](./项目评审报告.md) | 通读源码后的评审：评分、问题清单、改进建议 |

> 维护闭环：**定位**（项目架构.md）→ **安全改动**（模块维护方案.md）→ **验证**（维护方案的验证手册）→ **留痕**（更新日志/）。
