# 当前模块维护方案

> 更新：2026-11-12。模块入口见 [项目架构](项目架构.md)，旧维护卡保存在 [历史快照](archive/202609-模块维护方案.md)，不作为当前操作手册。

## 改动顺序

1. 读取 [领域术语](../CONTEXT.md) 与 [设计决策](architecture/decisions.md)，定位真实调用入口。
2. 在用户可观察的完整流程上复现问题，保留能证明行为的回归测试。
3. 修复后先跑类型检查与相关测试，再按风险完成全量门禁。
4. 在 [更新日志](更新日志/README.md) 记录根因、行为变化、检查结果和已知限制。

## 验证命令

| 命令 | 用途 |
|---|---|
| `npm run typecheck` | tsc --noEmit；修改 TypeScript 后首先执行 |
| `npm run build` | esbuild 转译并重建 dist；成功不代表类型正确 |
| `npm test` | Vitest 完整运行 `.test.ts` 和 `.test.tsx` |
| `npm test -- --run <test-file>` | 定向回归 |
| `npm run check` | Biome 格式与代码检查 |
| `npm run smoke` | 启动、信息命令、无 key 退出及会话路径 |
| `npm run smoke:package` | 实际打包并解包，检查发布文件、CLI、SDK 与版本说明 |
| `npm run docs:sync -- --check` | 当前文档数字、路径和验证口径 |

[CI](../.github/workflows/ci.yml) 已启用，覆盖 Linux 和 Windows，并验证实际发布包。[pre-commit](../.husky/pre-commit) 检查暂存源码并提示文档漂移。工具的读取权限、进程树结束和窗口行为要在实际支持的平台验证。

## 改动注意事项

- ESM 本地 import 使用 `.js` 后缀，类型依赖尽量使用 `import type`。
- 以调用行为判断模块职责，不为减少文件行数拆分模块。
- 读取工具的自动放行发生在禁止规则与敏感路径检查之后。
- 新增子上下文字段时区分约束和能力：保留限制不等于授予父会话的交互能力。
- 新增任务入口必须提供创建时的工作区和会话归属，不根据触发时的当前目录写回。
- 用户消息的回退标记是本地持久元数据，provider adapter 仅发送协议需要的消息字段。
- 新增 MCP / 本地工具时维护一个当前目录来源；禁止缓存启动时的列表作为长期视图。
- 不读取真实凭据来构造测试；文件与任务回归使用独立临时目录。
