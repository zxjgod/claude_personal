**待办（按收益排序）**：

- **C1（高）信息类命令快速通道**：`--version` / `--help` / 子命令判定层在加载 agent-loop/ink/openai 之前短路。fast-path.ts 已有雏形（bridge/cloud 拒绝在轻模块），但 cli.ts 顶层静态 import 使其失效。目标：`--version` < 200ms。做法：cli.ts 改为动态 import 重模块，或拆 slim entry。
- **C2（高）headless 免 TUI**：`-p` / stream-json 路径不加载 ink+react（约占总模块图相当比例）。动态 import runRepl/TUI 入口即可。
- **C3（中）highlight.js 按需**：全语言包 → 仅常用语言子集或懒加载（TUI 渲染时才载入）。
- **C4（中）双 SDK 裁剪**：openai 与 @anthropic-ai/sdk 是否都必须在依赖里？llm-adapter 若只用一个协议路径，另一个转 optional/peer 或删除。
- **C5（低）生产 node_modules 瘦身**：`npm prune --omit=dev` 文档化 + 发布打包脚本（可选）。
