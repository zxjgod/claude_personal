# 快速开始

本机启动 `Claude Code Replica` 并接入第三方 LLM API（OpenAI / DeepSeek / Qwen / Anthropic 等）。

## 一、前置要求

- Node.js 20+（`node -v` / `npm -v` 检查）
- 一个 OpenAI 兼容的 API key，或 Anthropic key

```bash
cd claude_personal
npm install
```

## 二、配置 `.env`

复制 `.env.example` 为 `.env`，至少填写：

```bash
LLM_PROVIDER=anthropic          # anthropic | openai | deepseek | qwen | moonshot | zhipu | custom
LLM_API_KEY=sk-your-key
LLM_MODEL=                      # 留空用 provider 默认模型
LLM_MAX_TOKENS=4096
LLM_TEMPERATURE=0.1
PERMISSION_MODE=default         # default | acceptEdits | bypassPermissions | plan
```

权限模式：

| 模式 | 行为 | 适用场景 |
|---|---|---|
| `default` | 只读自动放行，写/bash 询问 | **真实项目推荐** |
| `acceptEdits` | 编辑类自动放行 | 沙盒 / 临时目录 |
| `plan` | 只读规划，阻断所有写操作 | 先看分析再决定 |
| `bypassPermissions` | 基本全放行 | 不推荐用于重要目录 |

### 多 API 端点：在中转站 / 国内平台间热切换

如果你常在多个后端（中转站、DeepSeek、Kimi、通义等）之间切换，不必每次改 `.env` 重启。复制模板建立一份档案文件（已 gitignore，含明文 key 不会进版本库）：

```bash
cp .claude/providers.json.example .claude/providers.json
# 编辑后每个档案是一组 { name, provider, baseURL, apiKey, model }
```

会话内切换：
- `/provider` —— 打开方向键选择器（TUI 默认；`--no-tui` 真终端也支持），↑↓ 选、回车切。
- `/provider <名字>` —— 直接按名切换（支持唯一前缀，如 `/provider deep`）。

切换即时生效、零 token、无需重启；只有 `name` 必填，`provider` 缺省 `openai`，`baseURL`/`model` 缺省走该 provider 默认，`apiKey` 缺省沿用当前。

## 三、构建与启动

```bash
npm run build      # 生成 dist/，CLI 入口 dist/cli.js
npm start          # = node dist/cli.js，正式启动
npm run dev        # = tsx src/cli.ts，开发模式免 build
```

启动前可跑测试确认代码未坏：

```bash
npx vitest run
```

## 四、指定工作区启动

工具会把 Read/Write/Edit/Bash 限制在 `WORKSPACE_ROOT` 内。

**Git Bash / 沙盒联调：**
```bash
WORKSPACE_ROOT="$(pwd)/sandbox" PERMISSION_MODE=acceptEdits npm start
```

**PowerShell：**
```powershell
$env:WORKSPACE_ROOT = "$PWD\sandbox"
$env:PERMISSION_MODE = "acceptEdits"
npm start
```

不设置 `WORKSPACE_ROOT` 时默认用当前目录。

## 五、第一次真机联调

项目自带 `sandbox/` 示例目录（`README.md` / `package.json` / `src/math.js`）。用 `acceptEdits` 在沙盒里启动，输入：

```
Read src/math.js, then add a new exported function divide(a,b) that returns a/b. Use the edit tool. Keep existing functions.
```

预期：先 `read` → 再 `edit` → 显示耗时与 diff → 总结改动。检查文件是否真改：

```bash
cat sandbox/src/math.js
```

## 六、真实项目使用建议

```bash
WORKSPACE_ROOT="C:/你的/真实/项目路径" PERMISSION_MODE=default npm start
```

1. 真实项目先用 `default`（不要 `acceptEdits`/`bypassPermissions`）。
2. `git status` 确认干净，或先 commit。
3. 先让它只读分析：`先阅读项目结构，告诉我主要模块和启动方式，不要修改任何文件。`
4. 再给小任务，确认分析正确后才让它改。

## 七、CLI 内置命令

输入 `/` 开头的 slash 命令（部分）：

| 命令 | 作用 |
|---|---|
| `/help` | 显示所有命令 |
| `/status` | 会话状态（模型、tokens、改动） |
| `/cost` | token 用量与预估成本 |
| `/tools` | 列出已加载工具及来源 |
| `/context` | 上下文构成与 token 占比 |
| `/config` | 当前运行配置 |
| `/model <id>` | 切换模型 |
| `/effort [level]` | 推理强度滑块（low/medium/high/xhigh/max/ultracode） |
| `/compact` | 手动压缩上下文 |
| `/doctor` | 环境诊断 |
| `/sessions` `/resume <id>` | 列出 / 恢复会话 |
| `/diff` | 本会话文件改动 |
| `/permissions` | 查看/清空 always-allow 记忆 |
| `/memory [add <text>]` | 查看/追加 CLAUDE.md |
| `/init` | 扫描项目生成 CLAUDE.md 脚手架 |
| `/clear` | 清空对话 |
| `/tokens on\|off` | 切换 token 显示 |
| `exit` | 退出 |

## 八、其他用法

**`@文件`引用**：输入里写 `@src/math.js` 自动读取内容附加到上下文。只能引用 `WORKSPACE_ROOT` 内的文件，不能 `../` 逃逸。

**多行输入**：支持 ```` ``` ```` 代码块围栏，或行尾 `\` 续行。

## 九、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| `LLM_API_KEY is not set` | `.env` 未配 key，或不在项目根目录 |
| 401 / 403 | provider / key / model / baseURL 不对，或额度不足 |
| 工具不能改文件 | `PERMISSION_MODE=plan`、文件不在工作区内、或未先 Read 就 Edit（本项目要求 Read 后才允许 Edit） |
| 怕误改真实项目 | 用 `default` 模式，先分析后改动 |

管道冒烟测试（验证基础链路不崩）：

```bash
printf 'reply with exactly PONG\nexit\n' | WORKSPACE_ROOT="$(pwd)/sandbox" PERMISSION_MODE=acceptEdits node dist/cli.js
```

看到 `PONG` 和 `Goodbye!` 即正常。

## 十、安全建议

- 不要把 `.env` 提交到 git。
- 真实项目先用 `default` 或 `plan`。
- 大范围改动前先 `git commit` 或备份。
- 优先让它 Read/Grep/Glob 分析，再 Edit。
- 不要在 `bypassPermissions` 下指向重要目录。
