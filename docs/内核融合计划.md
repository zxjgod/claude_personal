# 内核融合计划（Kernel Fusion Plan）

> 目标：把 `参考文档/kernel/` 提炼的 Claude Code **7 根支柱**完整融合进本项目内核。
> 基准：`参考文档/kernel/{README,01-agent-loop,02-tool-system,03-permissions,04-system-prompt,05-subagents}.md`
> 现状评估：2026-06-30，对当前 `src/` 逐条对照内核规格得出。
> 范围决策：**全 7 支柱完整融合**（M26–M37）。

---

## 一、一句话结论

旧文档《项目对比-claude_personal-vs-claude-code.md》称"核心机制已基本对齐"。但**逐条对照内核规格后，真实融合度只到一半左右**，且发现一处真实安全漏洞（bypass 模式绕过全部安全检查）。

本计划把差距拆成 M26–M37 共 12 个里程碑，按"内核依赖顺序 + 影响/风险"排序，P0 先做安全与地基。

## 二、7 支柱融合度评分

| 支柱 | 融合度 | 一句话差距 |
|---|---|---|
| 1 主循环 | 🔴 低（1✅ / 7🟡 / 8🔴） | `needsFollowUp` 驱动✅，但无 typed return、无回合预算续写、压缩只有 2/5 层、token 靠重新分词不靠 usage |

**任务**：
- [x] 把 `isBlockedPath` + 危险模式安全检查**移到 bypass 短路之上**，建立"bypass 免疫"层
- [x] `BLOCKED_PATTERNS` 补 `.claude/` 目录（规格明确点名，当前缺）

**结果**：`checkPermission` 重排为 read-only → plan → **安全 floor（blocked paths + dangerous patterns，bypass 免疫）** → bypass → acceptEdits → default ask。改了 1 个原本编码漏洞的单测 + 1 个集成测试，新增 8 条红线断言。全套 691 测试通过，typecheck + biome 干净。
