### 成本分析

**单次调用成本**：
- Input tokens: ~300
- Output tokens: ~50
- **成本：$0.0001/次**（0.01 美分）

**月度成本估算**：

| 用户类型 | 危险操作/天 | 月成本 |
|---|---|---|
| Light user | 5 | **$0.015** |
| Medium user | 20 | **$0.06** |
| Heavy user | 50 | **$0.15** |
| Power user | 200 | **$0.60** |

**ROI 分析**：

假设中等用户（20 次危险操作/天）：
- 静态检查假阳性率：30%
- 假阳性导致的时间浪费：6 次/天 × 10 秒 = 1 分钟/天
- 月时间浪费：30 分钟
- 机会成本：$25（按 $50/小时计算）

**净收益**：
- Classifier 成本：$0.06/月
- 时间节省价值：$25/月
- **净收益：$24.94/月**
- **ROI：41,567%** 🚀
