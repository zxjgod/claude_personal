# 强停后恢复完整工具批次

> 2026-11-12 · fix / test · Headless、会话保存与跨进程恢复

原 Headless CLI 只在回合结束时保存会话。真实进程已经完成编辑，并发出下一次模型请求时强制结束，实际会话 ID 对应的保存文件仍不存在。复现以 `system/init` 返回的 ID 为准。

CLI 现在在接收用户输入后保存，并在 `tool_results` 边界等待保存完成再发出下一次模型请求。此时 assistant 工具调用与工具结果已完整配对。回合结束仍保存最终快照。保存失败会记录告警，`--no-session-persistence` 会跳过所有保存点。

离线端到端用例让实际 CLI 先读取文件并写入取整规则。下一次模型请求被挂起，此时对夹具所属 CLI 发送 `SIGKILL`，确认它没有返回最终结果。新进程从同一会话恢复，模型请求含原来的编辑结果。新需求把取整改为截断，测试核对同文件的用户注释保留，并独立执行正数和负数验收。

本轮验证边界是已保存的完整批次。若在工具执行中或新快照替换前强停，恢复以最近完整快照为准，磁盘上的部分改动可能需要重新检查。恢复推进时优先覆盖这段窗口、后台进程失去宿主，以及 workflow 副作用已执行但结果尚未落盘的情况。总体目标按用户要求在本轮结束后暂停。

收尾基点为 `main` 上的 `ed3afd2`，这轮及此前恢复推进的改动保留在本地工作区。计划顶部和日志索引均已登记当前继续入口。

本轮 Windows 双 worker 核心集 31 文件、369 项全部通过，耗时 149.98 秒。定向强停与协议回归 14 项通过，类型、代码和文档检查通过，发布包烟测通过（643 个文件）。最近一次全量运行属于上一轮 SDK 改动，结果为 3,268 通过、1 跳过。
