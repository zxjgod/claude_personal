# 自动压缩保留近期需求和更正

> 2026-11-14 · fix / test · 上下文连续性

用户对上一轮需求只改一处时，旧实现只逐字保留最新消息。测试用有损摘要复现：两次压缩后，“改用截断”仍在，但早先的“保留所有公开导出”消失。

现在按原顺序保留最近三条真实用户请求中符合条件的消息。最新请求沿用逐字保留规则。另两条需为纯文本，总计最多 12,000 字符。仍位于尾部的消息不会复制，合成用户消息不会占名额，工具调用和对应结果仍以完整批次为边界。较早的请求和旧附件由摘要承载。

定向回归 22 项通过，覆盖两次有损压缩、时间顺序、工具配对、旧附件、超长文本及尾部去重。`npm run eval:context -- 2 correction` 使用 `k3` 的两轮真实验收均通过，每轮触发两次压缩，耗时分别为 94.285 和 62.335 秒。两轮都保留了原始输入校验与受保护文件，并产出了符合更正要求的金额格式。报告保存在本地 `.claude/evaluations/1794630832626-27520.json`。
