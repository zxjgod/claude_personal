# 真实委派、审查和补丁整合

> 2026-11-12 · test / evaluation · SDK、CLI、Agent、工作树与补丁复验

`npm run eval -- examples/collaboration-suite.json --repeat=2` 使用已构建的 CLI 和第三方 `k3`（Anthropic 适配器）。主模型先观察基线失败，再委派隔离 worker 修改订单汇总。主模型执行独立测试，得到 SKU 匹配需忽略大小写的审查意见。它通过原 agent id 传回反馈，验证原工作树的修订，应用 Git 补丁，并在主目录运行测试。

评估器版本 4 支持 `initialEdits`，先创建夹具基线提交，再预置未暂存的笔记。外部 verifier 核对主模型工具顺序、两次 Agent 调用的身份、持久化 worker 对话中的实际编辑和 Git 工作树。它还检查候选补丁只涉及两个源码模块，主目录的未暂存笔记保留，另一份带相同笔记的仓库可重放补丁并重新通过测试。
