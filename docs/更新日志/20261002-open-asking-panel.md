# 询问面板对齐参考布局

- 日期：2026-10-02
- 提交主题：`feat: align asking dialogs with the reference layout`
- 范围：默认 TUI 与全屏 TUI 的权限、结构化提问、确认、MCP 表单及计划审批。

## 用户可见变化

- 使用一条浅紫细分隔线、开放面板、明确标题、灰色说明与编号选项。
- 权限标题根据实际工具表达操作；skill 说明只读取已加载的元数据，不执行模板。
- 对话框显示自己的快捷键提示，隐藏主输入区的模型 / 中断提示。
- AI 单选、多选提问支持 Tab 输入自定义回答。
- 权限询问支持 Tab 补充说明；提交会拒绝当前操作，将用户指示送入正常聊天流程。主回合运行时排队，后台询问则等其他弹窗关闭后提交。
- 保留箭头、数字、Enter、Esc、y/a/n 与权限面板 Shift+Tab；新增请求重置选中项和编辑状态。
- 配色支持深色和浅色主题；中文与 emoji 删除不切断 UTF-16 字符。
