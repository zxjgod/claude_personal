## 二、改动明细

### 21.1 工具集成 — `src/__tests__/integration-tools.test.ts`（23 用例）

真 git 全生命周期（无 git 环境自动 no-op）：

- **Worktree**：enter（head/fresh 回退）→ 在 worktree 内写文件 + commit → 断言 **main HEAD 不动、分支前进、新文件只在 worktree 不在主树**（提交隔离）；exit `keep` 留盘 / `remove` 删盘删分支；脏树拒删 + `discardChanges` 强删；**嵌套 worktree 栈 LIFO 弹出**；同名分支二次创建失败；非法字符净化；跨 session 栈隔离；非 git 目录报错。
- **Skill**：注册→解析+展开 prompt（带/不带 args）、override 覆盖旧 prompt、未知名列出活目录、空名报错。
- **Cron/Sleep**：多 job 注册 + `list`/`get`/`remove`（返回是否存在）、recurring+durable 标志落地、非法 cron 不注册、Sleep 带 prompt 入队 `+<delay>` 一次性 job、无 prompt 不入队且夹紧下限。

### 21.2 权限集成 — `src/__tests__/integration-permissions.test.ts`（21 用例）

完整 `checkPermission` 决策管道 × 可选 LLM 分类器，用录制式 fake `ModelCaller`：

- **短路顺序**：read-only / plan / bypass / blocked-path 在分类器之前返回 —— 断言 `callModel` **零调用**（既不浪费模型调用，也无法绕过 plan 硬阻断）。非标记的破坏性工具仍弹窗但**不**调分类器（分类器只对正则标记过的调用跑）。
- **三判决端到端**：BLOCK 不弹窗直接拒（reason=模型给的）、CONFIRM 用模型 reason 富化提示仍弹窗、ALLOW 退回正则 reason 仍弹窗。
- **失败安全**：无 apiKey / 抛错 / 不可解析 / 超时（慢流中途截断）/ 已 abort —— 一律退回正则 reason 并仍弹窗，绝不放松。
- **动作整形**：`formatActionForClassifier` 的 bash / edit / url / JSON 四形态（通过录制 caller 收到的 action 文本断言）。
- 工作区外写入被标记后 BLOCK 拒绝；每次标记调用都重新咨询分类器（无缓存）。

### 21.3 持久化集成 — `src/__tests__/integration-persistence.test.ts`（20 用例）

SessionMemory + SessionTranscript + memory-extract 协同 + 模拟重启：

- **多 session 隔离**：同 workspace 互不串、按 updatedAt 倒序列出、删一个不动其余；同 workspace 两实例互见、异 workspace 隔离。
- **resume**：新实例（模拟重启）读快照保 `createdAt`/`completed`；`messagesToTranscript` 把多轮（user/assistant/tool）折回 transcript items 且 tool 结果内联。

- **并发**：多 session 交错落盘各自最终态正确、单 tick 突发 append 保序。

## 五、设计决策记录

1. **MCP「真 mock server」而非打桩** —— stdio 用子进程跑真 SDK Server（`process.execPath` + fixture `.mjs`），http 用进程内 StreamableHTTP server，端到端验证包装/调用/权限/资源链路；只有 sse/ws 因"真起服务跨平台脆"降级为"路由构造 + 不可达端点优雅降级"覆盖。比 mock SDK 更能抓真实回归。
2. **fixture 放 `src/__tests__/fixtures/*.mjs`** —— biome `files.includes` 只含 `scripts/**/*.mjs`、tsc 无 `allowJs`，故该 `.mjs` 既不被 lint 也不被类型检查、又不匹配 vitest 的 `*.test.*` glob，不会被当测试收集。低层 `Server`（非 `McpServer`）免引 zod。
3. **分类器超时测试改"慢流中途截断"** —— `classifyPermissionRisk` 的超时是 `for await` **yield 间协作式**：从不 yield 的生成器无法被中断（会真挂）。故用"逐字符慢流、deadline 在 yield 间触发"模拟，截断后至多拿到不可解析的半截 verdict → unavailable，与真实"流到一半超时"一致。
4. **真 git 测试无 git 时 no-op** —— 沿用 `tools-m9.test.ts` 的 `hasGit` 模式；CI 镜像都带 git，本地 Windows 缺 git 时静默跳过而非失败。
